# TCG-Deck-Builder
This repository contains deck-building algorithms designed for one of my favorite card games, and will also contain a framework for other TCG Deck building algorithms.

WARNINNG: This repository is still in progress! Nothing is fully functional yet!

Order of layout:
Step 1: Card Identifiers: the goal is to parse a csv of card types/game pieces in order to create a dataset the algorithm can work with.
Step 2: Weighting Mechanisms: The following module will include weighting mechanisms for each card and game piece so that the algorithm can prioritize each piece.
Step 3: Categorizations and Sub-Categorization: This module will focus on categorizing each card and game piece so that, rather than rely on weights alone, will also evaluate based on given and shared attributes, pooling from shared attributes and staying consistent with them.
Step 4: Algorithms: This module will contain different algorithms for the card games and each algorithm will be refined/enhanced for consistency.
Step 5: GUI: If I have enough time, I may create a GUI module to make this program look less clunky. I've never been one to make a good GUI normally, but I will give it the old college try and make it look as presentable as possible.

Programmed in Python because this repository is more conceptual than fully functional at this stage.
